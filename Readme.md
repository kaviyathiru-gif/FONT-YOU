# Handwriting Style Keyboard (fontyou)

> Transform your unique handwriting into a custom virtual keyboard! ✍️⌨️

`fontyou` is a sleek, modern web application that allows users to upload a handwriting sample, analyze its structural characteristics (slant, consistency, spacing), generate a custom typography font, and preview/test it instantly in the browser.

---

## ✨ Features

* **Interactive Handwriting Upload:** Drag-and-drop or choose image files with instant visual preview.
* **AI Analysis Simulation:** Extracts metrics like font style, letter consistency, slant angle, and spacing.
* **Live Keyboard Preview:** Dynamic virtual keyboard rendering your custom font styles on the fly.
* **Custom Modal Alerts:** Clean, modern modal notifications replacing standard browser alerts.
* **Font Export & Installation Guide:** Download custom `.ttf` font packages and step-by-step mobile/desktop installation instructions.
